# Decision tree

Run it for each offer, in order. Write down each answer and the evidence for it.

```
1. Risk: could trouble here damage the parent, or the reverse?
   yes → separate (house of brands), or endorsed if the parent's credibility is essential and the risk is small
   no  → 2

2. Audience fit: would the two audiences be put off by each other?
   yes → separate or endorsed
   no  → 3

3. Equity transfer: does the parent's name help this offer sell?
   no  → endorsed or separate, if 4 and 5 justify a brand at all; otherwise branded house anyway, because a weak parent name still costs less than a new one
   yes → 4

4. Distinct promise: does this offer promise something the parent cannot?
   no  → branded house (parent plus descriptor), or a feature if it lives inside another product
   yes → 5

5. Investment: is there budget and attention to build a separate identity for years?
   no  → sub-brand at most
   yes → sub-brand or endorsed, depending on how much the parent should show
```

## Notes on each question

**Risk.** Think of reputational events: a data breach, a safety recall, a controversial product category, a regulator's action. Also think of the reverse: a struggling parent can drag down a healthy acquisition.

**Audience fit.** Luxury and discount, children and adult, enterprise and consumer are common clashes. Overlap alone is not the test; the test is whether either audience would think less of the brand for serving the other.

**Equity transfer.** Ask for evidence: awareness, preference, win rates when the parent's name appears. Without evidence, mark the answer as an assumption.

**Distinct promise.** If the honest description is "the same promise, for a different use", that is a descriptor, not a brand.

**Investment.** A brand needs a name check, trademarks, an identity, a site, a launch, and years of spend to become known. Small teams almost never have this for more than one or two brands.

## Acquisitions

Common sequence when the acquired brand has real equity: keep it, add an endorsement, measure, then decide whether to merge. Merging on day one throws away what was paid for. Keeping it separate forever throws away the reason to buy.
