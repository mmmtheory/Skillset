# Plan cards: spec

Frame: Pricing / Plans / Desktop and Mobile (last edited 3 Oct)

Three cards: Starter, Team, Business.

- Title: plan name, `title` style, `ink`
- Price: "$12 per month" (Team $29, Business $59), `body`, `muted`
- Button: "Choose plan". On the plan the person already has, the button is disabled and reads "Current plan".
- Desktop: three columns. Tablet: two. Mobile: one column, cards full width.
- States to build: button default, hover, focus, disabled.
