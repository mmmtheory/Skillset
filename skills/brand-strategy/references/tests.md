# Tests and the generic-word list

## The four positioning tests

| Test | How to run it | Fails when |
| --- | --- | --- |
| Swap | Replace the brand name with a named competitor in the positioning and the promise | The sentence still works |
| Proof | For each claim, write the evidence the business can show today | Evidence is a hope, a plan or "we believe" |
| Sacrifice | Write who the brand is happy to lose and one reasonable request it will refuse | Nothing is given up |
| Plain words | Say it as a customer would to a friend | It needs category jargon or the brand's own slogan |

Run all four on the positioning, the promise and each personality trait.

## Generic value words

These appear in most brand platforms and say nothing on their own. Use one only if the platform proves it with a behaviour or a fact, and prefer a specific replacement.

| Generic | Ask instead |
| --- | --- |
| innovative | What did you do first, and what can a customer do because of it? |
| trusted, trustworthy | What do you do that earns trust: a guarantee, a disclosure, a track record? |
| customer-centric, customer-first | Which decision did you make for customers that cost you something? |
| passionate | What do you care about enough to refuse work over it? |
| quality, premium | Which material, process or standard, measured how? |
| seamless, simple, easy | Which step did you remove, and how long does it take now? |
| empower, unlock, elevate | What can the person now do that they could not before? |
| authentic | Which true thing do you say that competitors won't? |
| community | Who, doing what together, how often? |
| sustainable | Which measurable change, against what baseline? |

## Purpose test

Ask: name one decision this purpose would make for us, which we would otherwise get wrong. If you cannot, the purpose is decoration. Drop it.

## Territory test

Distinct territories differ in what they ask the business to do, not just in tone. If two territories would lead to the same product, hiring and service decisions, merge them.
