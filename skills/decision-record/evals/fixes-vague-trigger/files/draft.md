# Dark mode

Status: Accepted
Date: 2026-10-01
Decider: Head of Design

## Decision
We aligned on an approach for dark mode.

## Context
Customers ask for dark mode. Building it properly needs semantic colour tokens, which we don't have yet.

## Options
A. Ship dark mode now by inverting colours
B. Introduce semantic tokens first, then ship dark mode in Q2 (chosen)
