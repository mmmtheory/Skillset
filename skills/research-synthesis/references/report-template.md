# Report template

```markdown
# <Study name>: synthesis

**What we learned**
Three sentences, one per top finding, plain enough to read aloud in a meeting.

**Research questions**
- Question (stated by the team, or *inferred* if you had to infer it)

**Method and sample**
N participants, how they were recruited if known, format (interviews, usability test, survey), source type (transcripts or notes), dates. One short paragraph.

## Insights

### 1. <Insight sentence: who, does what, because why, so what>

**Evidence:** Strong, 6 of 9 participants

> "Exact quote." (P3-Q14)

> "Exact quote." (P7-Q2)

**Counter-evidence:** P5 did the opposite because ... (or "None found.")

**Implication:** How might we ...?

### 2. ...

## Signals worth watching

- One-line description, n of N, why it is interesting.

## Hypothesis check

Only if the team named one: Supported, Not supported or Unclear, with one line of reasoning.

## What this research cannot tell us

- Limit, and what would answer it.
```

## Notes

- Order insights by how much they should change the team's next decision, not by count alone.
- Quote IDs come from the quote index (P3-Q14). Without an index, use the participant ID alone (P3).
- Keep each insight card under about 120 words. The quotes do the persuading.
- If the person asked for a slide outline, an email or a one-pager instead, keep the same content order and evidence labels.
